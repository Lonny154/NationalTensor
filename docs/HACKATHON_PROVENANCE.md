# National Tensor hackathon provenance audit

**Reviewed November 2, 2026.** This is a source and history audit for the October 26–November 4 Meta Global AI Developer Hackathon. It separates work shown in the demo from earlier [Matmul Inspector](https://github.com/Lonny154/Matmul-Inspector) work. A commit date shows when a file entered a repository, not when every line was first authored.

## Scope and method

I compared National Tensor `main` at [`e207a09`](https://github.com/Lonny154/NationalTensor/commit/e207a0951e776dc9807337f6d9c3ebcf6c410853) with Matmul Inspector `main` at [`5df8f5b`](https://github.com/Lonny154/Matmul-Inspector/commit/5df8f5ba3d76b9acc2e6af2b5c2e584ed21f5543) and its pre-event research branch at [`1637aa4`](https://github.com/Lonny154/Matmul-Inspector/commit/1637aa4). Matmul Inspector's visible history begins September 20; National Tensor's first visible commit is [`bd1d4b6`](https://github.com/Lonny154/NationalTensor/commit/bd1d4b6) on October 26. I inspected tracked Python, CUDA/Triton, tests, docs, dashboard code, and assets; reviewed relevant source and experiment reports; compared Git blob IDs, nontrivial Python function syntax trees, and normalized eight-line source windows. The tested snapshots had **zero exact shared blobs, zero exact nontrivial Python functions, and zero matching eight-line source windows**. This is strong evidence against unchanged or substantial verbatim copying in the reviewed snapshots, but it cannot prove independent authorship, detect all rewritten adaptations, or cover private/untracked material and every historical branch.

## Reuse and attribution

**Direct code reuse:** None substantiated in the compared tracked snapshots. No unchanged file, substantial verbatim source window, or nontrivial identical Python function was found. **Adapted code reuse:** None substantiated by the comparison; similar Triton GEMM structure and measurement routines are common patterns, so their precise ancestry remains uncertain. **Conceptual reuse:** Matmul Inspector supplied FC1 workload familiarity, the `512×3072×768` shape and `64×128×32`/four-warp/three-stage baseline configuration, controlled timing and A/A habits, correctness and hash gates, and compiler/profiler interpretation. Its October 19 stage-2 dogfood report is an explicit pre-event predecessor, not a National Tensor speedup. National Tensor's new experiment code, saved runs, Muse interactions, evidence exports, and dashboard should be described as new *repository work* with this lineage disclosed.

These are imports/dependencies, not vendored source. `requirements-dashboard.txt` lists Flask only; no lockfile fixes all runtime or transitive versions, so this is not a complete installed-package license inventory.
- **Visual/audio:** the tracked National Tensor tree contains no raster image, font, video, or audio media file. Review any *separate recorded video* for music, imagery, fonts, and logos before publication; its file and edit history were unavailable here. ## Submission guidance and unresolved questions

The current [recording guide](dashboard.md) describes National Tensor features, but gives no prior-work disclosure. Add a spoken 10–15-second line early in Research Overview: “Matmul Inspector was my earlier GPU analysis project. National Tensor's Muse workflow, these new measurements, evidence bundle, and dashboard were built for this hackathon. The prior project informed our benchmark method and FC1 setup.” Keep the stage-direction confirmation, unresolved cause, and inconclusive Muse score explicit. The already recorded video was not inspected or edited in this audit; verify whether it contains the disclosure and revise the submission narration or recording if needed.

Before submission, confirm the video's third-party assets and narration, the intended National Tensor license, and whether any untracked/private source or pre-event draft was incorporated. The available commits and source comparison support the classifications above, but cannot settle those questions or establish eligibility on their own.
