## Boundary-tile arithmetic and discriminating design

For the recorded 64×128×32 tiles, 128/64 = **2** M tiles, 3072/128 = **24** N tiles, and 768/32 = **24** K steps, all with zero remainder. Thus the named 128×3072×768 workload has **no partial M, N, or K tiles**. This is exact dimensional arithmetic and agrees with Experiment 003's limitation. It does not prove that a future specialized kernel removes predicates, launches no edge-handling logic, or improves latency; those depend on the actual implementation and compiler output.

Experiment 004's 130×3072×768 shape has `ceil(130/64) = 3` M tiles, with **two valid rows in the last tile**; N and K remain divisible. It would exercise a partial-M edge path if a P02 implementation actually dispatches one for that shape. M=129 through M=191 also yield a partial third M tile at this block size. A revised experiment should pair M=128 as a full-tile control with a shape such as M=130 to test edge coverage, while comparing **specialized versus uniform-masked variants within each identical workload**. Do not interpret M=128 versus M=130 latency as an optimization effect, because shape changes alter work. Verify exact tile coverage, masks, numerical equivalence, and reduction order for each implementation. For the fixed M=128 hypothesis, assess whether a full-tile fast path changes compiled executable instructions and, only if it does, measure any latency effect with a matched control. For M=130, separately assess correctness and the costs or benefits of the edge dispatch. These are proposed tests, not experiments performed in this review.

## Materiality and integrity

The interval-category error and omitted observation keys are genuine scientific/provenance limitations. They do not create a fabricated P02 measurement or reverse the criticism's main conclusion that P02 is untested and a compiler-level gate is warranted. The unexercised M=128 edge path is more consequential: it means the proposed fixed-shape test can test a full-tile specialization but **cannot validate edge-path behavior or benefit**. A reviewer accepting this criticism should preserve that distinction when interpreting any future Experiment 009 B decision. The reviewer may instead reject if these limitations make the unmodified criticism unsuitable as treatment text; the frozen v1 response itself must not be edited.
