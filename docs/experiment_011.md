# Experiment 011 — v3.1 scalar-path feasibility

## Purpose and boundary

This one-request feasibility test asks whether making the scalar `value_path` convention explicit helps Muse comply with the same P06 atomic-claim response schema that Experiment 010 used. It does **not** change the v3 validator, accept the rejected Experiment 010 response, alter Experiment 009, or establish improved scientific reasoning.

The separately identified prompt version is `experiment_008_critic_prompt_v3_1`; the required **response schema remains** `experiment_008_critic_v3`, checked by the existing `parse_critique_v3`. The original v3 prompt function and Experiment 010 prompt bytes remain unchanged. The new prompt is generated by `muse_research_critic_v31.py`; the separately versioned request/audit path is `muse_critic_feasibility_011.py`.

## Exact prompt changes from Experiment 010

Only prompt presentation changed:

1. Append the instruction: “Every observation MUST include value_path. Use [] when observation_key directly contains the recorded scalar; use a nonempty path only to select a nested value.” The rest of the added sentence points to the two examples and says to copy schema fields rather than unsupported values.
2. Set the observation placeholder in `SCHEMA` to `"value_path": []`, removing the ambiguous `["nested key if needed"]` placeholder.
3. Add an `EXAMPLES` section with two complete observation objects drawn from the validated source: E005 `confirmation_status: "missing"` with `value_path: []`, and E005 `screening:128x3072x768:grouped_m4` `median_paired_ratio: 0.9942989053504223` with `value_path: ["median_paired_ratio"]`. Each example has all seven required observation fields, including evidence ID, key, value, and unit.

The `AGGREGATE_SETS` and `SOURCE` sections are byte-identical to the Experiment 010 prompt. The added examples are instructions, not new measurements. The first example addresses the precise C6/C7 omission; the second protects nested-path usage. The strict v3 schema still rejects a missing `value_path`; the new prompt does not silently supply one.
